# Продуктовая спецификация

Полное описание логики электронного дневника для [IT Camp Sochi](https://itcampsochi.ru/).

## Для кого

Единый клиент для детей и родителей. Основные пользователи — дети **7–14 лет**. У студента и родителя **один аккаунт**.

## Регистрация и вход

- Учётную запись создаёт учебная часть.
- Логин и пароль отправляются на почту родителя или ребёнка.

### «Забыли пароль»

**1. Восстановление по почте** — указать привязанную почту. Логин и пароль приходят **автоматически**, данные аккаунта не меняются.

**2. Заявка через форму** — если нет доступа к почте: ФИО, дата рождения, контактная почта, номер группы. Учебная часть проверяет. Статус: **новая → обработана / отклонена**.

### Смена пароля

Только через учебную часть. Студент сам сменить не может.

### Отчисление

При статусе **«отчислен»** войти нельзя — сообщение обратиться в учебную часть. Данные в архиве.

## Личный кабинет и настройки

**Профиль:** ФИО, город (по умолчанию Сочи), школа, телефон, почта, дата рождения, фото.

Студент меняет только **город** и **фото**. Фото — с модерацией учебной частью; пока на проверке, повторная загрузка недоступна.

**Заполненность профиля** — чеклист или процент. За полное заполнение — **5 монеток** (разово).

**Отзывы преподавателей** — кто, предмет, дата, текст. Видны студенту и родителю.

**Перевод в другую группу** — новое расписание, рейтинг, ДЗ. История оценок и монеток сохраняется.

## Главная страница

### Рейтинг

- **Период:** календарный месяц, пересчёт каждый день
- **Формула:** 50% средний балл (2–5) + 50% доля ДЗ, сданных вовремя и зачтённых
- Виджет на главной + страница «Рейтинг» с архивом прошлых месяцев

### Графики

Оценки и посещаемость. На главной — график **за текущую неделю**. «Подробнее» → страница оценок (там период: день / неделя / месяц).

### Виджеты

- Домашние задания — счётчики «на проверке» и «просроченные»
- Журнал — последние 7 дней

## Домашние задания

| Статус | Описание |
| --- | --- |
| Текущие | Срок не истёк, работу ещё не сдали |
| На проверке | Работа загружена |
| Проверенные | Зачтено |
| Отклонённые | Нужно переделать и загрузить заново |
| Просроченные | Срок прошёл, работу ещё не сдали |

**Карточка:** заголовок, дата выдачи, тема, преподаватель, обложка предмета, срок, статус, «Скачать» / «Загрузить».

- Без группировки по датам и без выбора периода
- Сначала 8 заданий, кнопка «Показать ещё» подгружает по 4
- Можно удалить ошибочную загрузку и загрузить заново
- Отклонённое — виден комментарий преподавателя; после перезагрузки статус **«На проверке»**
- Монетки — только если сдано **до срока** и зачтено

## Журнал

Лента событий с фильтром и подгрузкой:

- Посещение, сдача ДЗ, сдача экзамена, оценка, монетки, отзыв преподавателя, опрос, заказ в маркете, отзыв на Яндекс

Push-уведомлений нет.

## Монетки

Баланс — в шапке и в маркете. Раздел «Мои монетки»: история, прогресс серий.

| Действие | Монетки |
| --- | --- |
| Посещение («присутствовал») | 1 |
| ДЗ вовремя и зачтено | 3 |
| Оценка 5 за ДЗ | +2 |
| Серия 5 / 10 / 20 без пропусков | 5 / 8 / 10 |
| Серия 5 / 10 / 20 без опозданий | 3 / 5 / 8 |
| Полный профиль | 5 (разово) |
| Поощрение на уроке | 1–5 (≤5 на всех за занятие) |
| Отзыв на Яндекс | 10 (разово на аккаунт) |
| Опрос | 2 |

**Правила:** за просроченное ДЗ монеток нет; «опоздал» — монетка за пару не даётся, но день не пропуск для серии; серии — по учебным дням; два независимых счётчика (пропуски / опоздания).

### Отзыв на Яндекс

1. «Оставить отзыв» → обучающее видео
2. Отзыв на Яндекс по инструкции
3. Ссылка в дневник → «Отправить на проверку»
4. Учебная часть проверяет → начисление монеток

## Опросы

Модальное окно при создании или **при следующем входе**. Пройти или отказаться (повторно нельзя). За прохождение — 2 монетки.

## Расписание

Виды: **день**, **неделя**, **месяц**.

Отменённые занятия скрыты. Прошедшие — без действий (можно только посмотреть детали).

**Занятие:** предмет, время, преподаватель, аудитория или «онлайн» со ссылкой (ссылка активна, пока занятие не закончилось).

Карточка **раскрывается** по клику — не модальное окно.

## Оценки

Шкала **2–5** (5 — отлично, 4 — хорошо, 3 — удовл., 2 — неудовл.).

**Шапка экрана:** средний балл за период, мини-график динамики, последние оценки.

**Фильтры:** предмет, тип работы (классная / домашняя / экзамен / контрольная), период день | неделя | месяц (по умолчанию текущий календарный месяц). Виды: сводный (по предметам) и детализированный (список).

**Карточка оценки** раскрывается на месте (как занятие в расписании): преподаватель, тип работы, комментарий, монетки за пятёрку по ДЗ (+2, только вовремя и зачтено).

**Маркеры:** отлично, экзамен, пересдача, не аттестован, с опозданием.

**Мотивация на экране:** вклад среднего балла в рейтинг месяца (50%) и монетки за пятёрки по ДЗ. Без оценки за занятие посещаемость на этом экране не показывается.

## Экзамены

Период: текущий месяц или весь период обучения.

**Статусы:** ожидает загрузки → загружено → проверено / пропущено.

Загрузка **один раз**. Кнопка активна до даты проверки.

## Маркет

Каталог от учебной части: мерч, канцелярия, игрушки. Цена в монетках индивидуально.

Покупка → списание монеток → заказ **«оформлен»**. Выдача **в школе на занятиях**. Студент заказ не отменяет.

**Статусы заказа:** Оформлен → Готов к выдаче → Получен.

## Платежи

Страница для ребёнка и родителя.

- **Реквизиты** — ИНН, БИК, счёт, назначение с персональным кодом
- **График** — дата, описание, сумма; задолженность автоматически
- **История** — дата, назначение, сумма

Период по умолчанию — текущий месяц.

## Ключевые правила (шпаргалка)

| Тема | Правило |
| --- | --- |
| Оценки | 2–5, «отлично» = 5 |
| Рейтинг | Месяц, 50/50 |
| Монетки за ДЗ | Только вовремя + зачтено |
| Пароль | Смена только через учебную часть |
| Отчисление | Вход закрыт |
| Заказы | Отмена только учебной частью |
