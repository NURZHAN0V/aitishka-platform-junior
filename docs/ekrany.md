## Главная

**Виджеты:**

1. Приветствие + баннер
2. Мой рейтинг — место в группе, балл, топ-5
3. Домашние задания — счётчики «на проверке» и «просроченные»
4. Серии и монетки — прогресс без пропусков / без опозданий, подсказка про профиль
5. Оценки и посещаемость — мини-график за текущую неделю, средняя посещаемость
6. Журнал — последние события (7 дней)
7. Быстрые ссылки — расписание, экзамены, маркет, рейтинг

## Расписание

**Переключатели:** День | Неделя | Месяц. Кнопка «Сегодня» возвращает к текущему периоду.

| Вид | Поведение |
| --- | --- |
| День | Занятия выбранного дня: сначала «идёт сейчас», затем ближайшие по времени. Для сегодня — блок «Дальше на этой неделе» (до 3 занятий). Если день пуст — подсказка и ближайшее следующее |
| Неделя | 7 колонок Пн–Вс на широком экране; на узком — список дней. Текущий день с кольцом и бейджем «Сегодня» |
| Месяц | Сетка текущего месяца с точками предметов; клик по дню открывает вид «День» |

**Карточка занятия:** предмет, время, статус. Клик раскрывает детали (преподаватель, аудитория / онлайн). Тему задаёт преподаватель в начале занятия — в расписании её нет.

**Статусы:** Скоро · Идёт сейчас · Прошло. Прошедшие — приглушены, без кнопки перехода.

Прошедшие занятия — без действий. Отменённые — не показываются.

## Оценки

Маршрут: `/grades`. Макет отдельный отсутствует — визуально как расписание и главная (токены, `AppLayout`, карточки предметов).

**Быстрый доступ (верхняя полоса):**

1. Средний балл за выбранный период (шкала 2–5) + качественная подпись
2. Динамика успеваемости — мини-график (sparkline), без тяжёлой chart-библиотеки
3. Последние оценки с иконкой предмета и маркерами статуса

**Мотивация:** вклад оценок в рейтинг месяца (50% средний балл + 50% ДЗ вовремя) и монетки за пятёрки по ДЗ (+2, если сдано вовремя и зачтено).

**Панель:** период День | Неделя | Месяц (по умолчанию текущий календарный месяц), фильтры предмета и типа работы, переключатель Сводный | Детализированный.

**Список:**

| Вид | Поведение |
| --- | --- |
| Сводный | Карточки предметов: средний балл, число оценок, маркеры последней |
| Детализированный | Карточки оценок; клик раскрывает детали на месте (преподаватель, тип, комментарий, монетки) |

**Маркеры (BaseChip):** Отлично · Экзамен · Пересдача · Не аттестован · С опозданием.

Пустой период и «пусто по фильтрам» — в стиле empty-карточек расписания.

## Домашние задания

Маршрут: `/homework`. Макет: [domashnie-zadaniya.jpg](../design/references/domashnie-zadaniya.jpg).

**Быстрый доступ:** счётчики «на проверке» и «просроченные» (клик открывает вкладку).

**Панель:** фильтр предмета, без выбора периода.

**Фильтры-вкладки:** Текущие · На проверке · Проверенные · Отклонённые · Просроченные (с числом в каждой). Несданная работа до срока — «Текущие»; после срока — «Просроченные»; отклонённая и ждущая перезагрузку — «Отклонённые».

**Список:** сначала 8 заданий, кнопка «Показать ещё» подгружает по 4.

**Карточка:** обложка предмета, статус, название, тема, преподаватель, срок (цвет: зелёный / жёлтый / красный), кнопки «Скачать» и «Загрузить». Клик раскрывает описание, материалы и комментарий преподавателя.

**Модал загрузки:** drag-and-drop или выбор файла → «Отправить». Успех — тост «Работа отправлена на проверку». На проверке можно удалить файл и загрузить заново.

## Экзамены

Маршрут: `/exams`. Макет отдельный отсутствует — визуально как домашние задания и оценки.

**Быстрый доступ:** счётчики «ожидают загрузки», «ближайшие сроки» и «пропущено» (клик открывает вкладку). Полоса ближайших экзаменов с маркерами Срочно / Скоро.

**Мотивация:** оценка 2–5 входит в средний балл; рейтинг месяца — 50% средний балл + 50% ДЗ вовремя. За экзамен монетки не начисляются.

**Панель:** период Месяц (по умолчанию текущий) | Весь период, фильтр предмета, переключатель Сводный | Детализированный.

**Фильтры-вкладки:** Все · Ожидает загрузки · Загружено · Проверено · Пропущено.

**Карточка:** предмет, преподаватель, оценка, конечная дата, дата проверки, статус. Клик раскрывает программу, материалы и рекомендации. «Загрузить» — один раз, кнопка до даты проверки; после оценки файл можно открыть.

## Рейтинг

Маршрут: `/rating`. Макет отдельный отсутствует — визуально как виджет «Мой рейтинг» на главной ([glavnaya.jpg](../design/references/glavnaya.jpg)).

**Период:** календарный месяц, по умолчанию текущий. Можно открыть прошлый месяц (архив). Пересчёт каждый день; в новом месяце счётчики обнуляются.

**Формула:** 50% средний балл за месяц (шкала 2–5) + 50% доля ДЗ, сданных вовремя и зачтённых.

**Слева:** место в группе («N из M»), баллы, период, динамика относительно прошлого месяца (↑/↓), два прогресс-бара — средний балл и ДЗ вовремя.

**Справа:** топ лидеров группы, строка текущего пользователя выделена. «Вся таблица» раскрывает полный список на этой же странице (без отдельного маршрута).

**Мобильные:** компактная сводка; прогресс-бары и лидеры раскрываются по кнопке «Показать детали».

**Мотивация:** монетки в рейтинг не входят; средний балл и ДЗ вовремя влияют и на место, и на начисления.

## Маркет

**Каталог:** сетка товаров, фильтр по категории (Все / Мерч / Канцелярия / Игрушки), сортировка.

**Карточка товара:** фото, название, цена в монетках, кнопка «Купить» / «Не хватает монеток» / «Нет в наличии».

**Покупка:** модал с балансом после покупки, пометка «Забрать в школе на занятиях».

## Меню профиля (шапка)

Открывается по клику на блок с аватаром в шапке. Белая карточка со скруглением, тень.

**Шапка меню:** аватар, ФИО, группа.

**Пункты в MVP:**

| Пункт в макете | Куда ведёт |
| --- | --- |
| Мой профиль | Личный кабинет |
| Настройки аккаунта | Настройки (город, фото) |
| Помощь и поддержка | Контакты школы ([itcampsochi.ru](https://itcampsochi.ru/)) |
| Выйти из аккаунта | Выход из дневника |

**Не входит в MVP** (на макете есть, в продукте не делаем):

- Уведомления — push нет, студент смотрит «Журнал»
- Безопасность — смена пароля только через учебную часть
- Связанные аккаунты — один аккаунт на студента и родителя

## Вход (без макета)

- Поля: логин, пароль
- «Забыли пароль» → восстановление по почте или форма заявки
- Отчислённый студент — экран с просьбой обратиться в учебную часть
