## Главная

**Шапка:** приветствие «Привет, …» на широком экране; на телефоне скрыто (остаются монетки и аватар).

**Виджеты:**

1. Приветствие + баннер
2. Мой рейтинг — место в группе, балл, топ-5
3. Домашние задания — счётчики «на проверке» и «просроченные»
4. Серии и монетки — прогресс без пропусков / без опозданий, подсказка про фото
5. Оценки и посещаемость — средняя посещаемость + мини-график за текущую неделю; на телефоне панель **складывается** (сводка над графиком)
6. Журнал — последние события (7 дней)
7. Быстрые ссылки — расписание, экзамены, маркет, рейтинг

## Расписание

**Навигация по дате:** общий компонент `PeriodNav` (стрелки + подпись периода + «Сегодня») — тот же паттерн, что у оценок.

**Переключатели вида:** День | Неделя | Месяц — только на широком экране (**> 1280px**). Уже — только вид «День» и `PeriodNav` по дням.

| Вид | Поведение |
| --- | --- |
| День | Занятия выбранного дня: сначала «идёт сейчас», затем ближайшие по времени. Для сегодня — блок «Дальше на этой неделе» (до 3 занятий). Если день пуст — подсказка и ближайшее следующее |
| Неделя | 7 колонок Пн–Вс. Текущий день с кольцом и бейджем «Сегодня» |
| Месяц | Сетка текущего месяца с точками предметов; клик по дню открывает вид «День» |

**Карточка занятия:** предмет, время, статус. Клик раскрывает детали (преподаватель, аудитория / онлайн). Тему задаёт преподаватель в начале занятия — в расписании её нет.

**Статусы:** Скоро · Идёт сейчас · Прошло. Прошедшие — приглушены, без кнопки перехода.

Прошедшие занятия — без действий. Отменённые — не показываются.

## Оценки

Маршрут: `/grades`. Макет отдельный отсутствует — визуально как расписание и главная.

**Верхняя полоса (только > 900px):** средний балл за период + качественная подпись и мини-график динамики. На планшете/телефоне полоса скрыта.

**Мотивация:** средний балл входит в рейтинг за всё время (50% + 50% ДЗ вовремя); монетки за пятёрки по ДЗ (+2 вовремя и зачтено).

**Панель:** период День | Неделя | Месяц (на ≤900px — только день) и общий `PeriodNav` по дате. **Без** фильтров предмета / типа работы и **без** режимов «сводный / детализированный» — один список карточек оценок.

**Список:** карточки оценок; клик раскрывает детали на месте (преподаватель, тип, комментарий, монетки).

**Маркеры (BaseChip):** Отлично · Экзамен · Пересдача · Не аттестован · С опозданием.

Пустой период — в стиле empty-карточек расписания.

## Домашние задания

Маршрут: `/homework`. Макет: [domashnie-zadaniya.jpg](../design/references/domashnie-zadaniya.jpg).

**Быстрый доступ:** счётчики «на проверке» и «просроченные» (клик открывает вкладку).

**Панель:** фильтр предмета, без выбора периода.

**Фильтры-вкладки:** Текущие · На проверке · Проверенные · Отклонённые · Просроченные (с числом в каждой). Несданная работа до срока — «Текущие»; после срока — «Просроченные»; отклонённая и ждущая перезагрузку — «Отклонённые».

**Список:** сначала 8 заданий, кнопка «Показать ещё» подгружает по 4.

**Карточка:** обложка предмета, статус, название, тема, преподаватель, срок (цвет: зелёный / жёлтый / красный), кнопки «Скачать» и «Загрузить». Клик раскрывает описание, материалы и комментарий преподавателя.

**Модал загрузки:** drag-and-drop или выбор файла → «Отправить». Успех — тост «Работа отправлена на проверку». На проверке можно удалить файл и загрузить заново.

## Экзамены

Маршрут: `/exams`. Макет отдельный отсутствует — визуально как домашние задания и оценки.

**Быстрый доступ:** счётчики «ожидают загрузки», «ближайшие сроки» и «пропущено» (клик открывает вкладку). Полоса ближайших экзаменов с маркерами Срочно / Скоро.

**Мотивация:** оценка 2–5 входит в средний балл; рейтинг — 50% средний балл + 50% ДЗ вовремя. За экзамен монетки не начисляются.

**Панель:** список за весь период обучения (без переключения месяца); фильтр предмета.

**Фильтры-вкладки:** Все · Ожидает загрузки · Загружено · Проверено · Пропущено.

**Карточка:** предмет, преподаватель, оценка, конечная дата, дата проверки, статус. Клик раскрывает программу, материалы и рекомендации. «Загрузить» — один раз, кнопка до даты проверки; после оценки файл можно открыть.

## Рейтинг

Маршрут: `/rating`. Макет отдельный отсутствует.

**Период:** всё время обучения — **без** вкладок месяца / недели. Пересчёт каждый день.

**Шапка:** заголовок «Рейтинг» и подсказка с формулой (tooltip).

**Формула:** 50% средний балл за всё время (шкала 2–5) + 50% доля ДЗ, сданных вовремя и зачтённых.

**Таблица:** место, ФИО, средний балл, ДЗ вовремя, баллы. Строка текущего студента выделена. На узком экране — карточки вместо таблицы.

**Мотивация:** монетки в рейтинг не входят; средний балл и ДЗ вовремя влияют и на место, и на начисления.

## Журнал

**Виджет на главной:** события за последние 7 дней, ссылка «Весь журнал» → `/journal`.

**Панель:** чипы-фильтры «Все» и по типам событий (с числом в каждом).

**Типы:** посещение · сдача ДЗ · сдача экзамена · оценка · монетки · отзыв преподавателя · опрос · заказ в маркете · отзыв на Яндекс на проверке.

**Лента:** сначала 12 событий, кнопка «Показать ещё» подгружает по 12. Карточка: иконка, что случилось, контекст (предмет / задание), дата. Клик по связанным типам ведёт в раздел (ДЗ, оценки, экзамены, расписание, маркет, отзывы).

Push-уведомлений нет — журнал основной способ узнавать, что произошло.

**Связи:** меню профиля в шапке → «Мои отзывы»; события журнала «Получил отзыв от преподавателя» → `/reviews`.

## Платежи

Маршрут: `/payments`. Макет отдельный отсутствует — визуально как остальные разделы (токены, `AppLayout`, карточки).

**Только просмотр** — данные вносит учебная часть. Одна страница для ребёнка и родителя.

**Панель:** период Месяц (по умолчанию текущий) | Весь период; для месяца — навигация стрелками и «Текущий месяц».

**Блоки:**

1. **Реквизиты** — получатель, ИНН, БИК, расчётный счёт, банк, код студента, назначение платежа с персональным кодом. Кнопка «Скопировать» у каждого поля и «Скопировать всё».
2. **График платежей** — таблица «Оплатить до | Описание | К оплате» (фильтр по месяцу даты). **Задолженность** = сумма по наступившим строкам графика − сумма всех оплат; красная строка с минусом — только если задолженность > 0.
3. **История платежей** — таблица «Дата | Назначение платежа | Оплачено» (фильтр по месяцу даты оплаты).

**Связи:** сайдбар «Финансы» → Платежи.

**Клавишленд `/games/keyland`:**

1. Выбор режима: буквы RU/EN, слова RU/EN, знаки препинания, цифры и символы.
2. Партия: таймер, строка текста (набранное / текущий / остаток), экранная клавиатура с подсветкой **следующей** клавиши. Без рук и пальцев. Ввод с физической клавиатуры. «Сдаться» → итог.
3. Итог: время, набрано, скорость (зн/мин), точность; «Ещё раз» / «Завершить» (в лобби). Результат пишется в `localStorage`.

## Личный кабинет (мой профиль)

Маршрут: `/profile`. Макет меню: [profil-modal.jpg](../design/references/profil-modal.jpg). Отдельного макета экрана нет — визуально как остальные разделы.

**Данные:** по порядку ФИО → группа → школа → телефон → почта → дата рождения — все только просмотр. Аватар кликабелен → `/settings`. Без чипа «Отклонено» и без причины отклонения (они только в настройках). Филиал — Сочи; поля «город» нет.

**Редактирование:** на этом экране ничего не меняется. **Фото и аватарку** — только в «Настройках аккаунта». Остальное задаёт учебная часть.

Один текущий аватар в шапке, профиле и настройках (общий session state).

**Подарок:** правая колонка — polaroid («IT CAMP» / «Гимназия №16») и призыв загрузить **своё** фото: **+5 после одобрения**. Без чеклиста и процента полноты. Состояния: нет подарка → CTA в `/settings`; на проверке — «ждём одобрения»; одобрено — «подарок получен» и ссылка в монетки. Clay-аватарка подарок не даёт. ## Настройки аккаунта

Маршрут: `/settings`. Макет меню: [profil-modal.jpg](../design/references/profil-modal.jpg). Отдельного макета экрана нет — визуально как остальные разделы.

**Фокус:** **фото/аватарка** (единственное место смены) и привязка Яндекс / ВКонтакте (мок: кнопка «Привязать …» ↔ «Отвязать …», без реального OAuth). Не дублирует весь личный кабинет — краткая подсказка и ссылка на `/profile`.

**Фото и аватар:**

1. **Загрузка файла** — статусы нет фото / на проверке / одобрено / отклонено (с причиной). Пока на проверке — повторная загрузка недоступна. Модерация учебной части (mock на клиенте).
2. **Генерация аватарки** — DiceBear **Clay** с анимацией (локально через `@dicebear/core` + `@dicebear/styles`, seed → SVG data URL, без HTTP API). Сразу становится текущим фото, **без модерации**. Seed пишется в `localStorage` и восстанавливается при следующем открытии. Модалка: один превью + «Выбрать» / «Сгенерировать».

Города в настройках нет. **Связанные аккаунты:** Яндекс и ВКонтакте — привязать / отвязать (мок).

**Связи:** меню профиля в шапке → «Настройки аккаунта».

## Меню профиля (шапка)

Открывается по клику на блок с аватаром в шапке. Белая карточка со скруглением, тень.

**Шапка меню:** аватар, ФИО, группа.

**Пункты в MVP:**

| Пункт в макете | Куда ведёт |
| --- | --- |
| Мой профиль | Личный кабинет (`/profile`) — просмотр; виджет «Подарок» справа |
| Мои отзывы | Отзывы (`/reviews`) |
| Настройки аккаунта | Настройки (`/settings`) — фото (модерация), привязка Яндекс/ВКонтакте |
| Помощь и поддержка | Страница помощи (`/help`) — контакты школы и FAQ |
| Выйти из аккаунта | Выход из дневника |

**Не входит в MVP** (на макете есть, в продукте не делаем):

- Уведомления — push нет, студент смотрит «Журнал»
- Безопасность — смена пароля только через учебную часть

Привязка Яндекс / ВКонтакте — на экране «Настройки аккаунта» (мок bind/unbind), не отдельный пункт меню.

## Вход (без макета)

- Поля: логин, пароль
- «Забыли пароль» → восстановление по почте или форма заявки
- Отчислённый студент — экран с просьбой обратиться в учебную часть
