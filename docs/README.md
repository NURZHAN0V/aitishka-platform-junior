## Кратко

- **Пользователи:** дети 7–14 лет и их родители (один аккаунт на семью).
- **Язык интерфейса:** русский.
- **Валюта:** монетки (начисление за учёбу и активность, трата в маркете).
- **Оценки:** шкала 2–5.
