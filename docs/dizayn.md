## Брендинг

По макетам:

- **Название в интерфейсе:** IT ШКОЛА Сочi / IT ШКОЛА Сочи
- **Логотип:** изометрический куб (цветные грани)
- **Маскот:** робот в боковом меню (декоративный элемент)
- **Тон:** дружелюбный, «игровой», для детей 7–14 лет — яркие карточки, скругления, иллюстрации

## UI-kit (из макетов)

### Цвета

| Назначение | Пример |
| --- | --- |
| Основной (кнопки, активное меню) | Фиолетовый `#8B5CF6` |
| Успех / проверено | Зелёный `#10B981` |
| Предупреждение / на проверке | Жёлтый `#F59E0B` |
| Ошибка / просрочено / отклонено | Красный `#EF4444` |
| Информация | Синий |
| Монетки | Золотой / жёлтый |

### Скругления

Карточки и кнопки: **12–24 px** (крупные блоки — больше радиус).

### Кнопки

- **Primary** — фиолетовая заливка
- **Secondary** — белая с обводкой
- **Link** — текстовая ссылка

### Статусы домашних заданий (цвет чипа)

| Статус | Цвет |
| --- | --- |
| Текущие | Фиолетовый |
| На проверке | Жёлтый |
| Проверенные | Зелёный |
| Отклонённые | Красный |
| Просроченные | Оранжевый |
| Не сданные | Серый |

### Предметы в расписании

У каждого предмета — **свой стабильный цвет** (точки в календаре, полоска в карточке занятия). Примеры из макета расписания: Python — синий, Scratch — оранжевый, Roblox — фиолетовый.

## Шапка

На всех экранах (кроме входа):

- Хлебные крошки
- Баланс **монеток** (иконка + число)
- Аватар, ФИО студента, группа — по клику открывается **меню профиля** ([profil-modal.jpg](../design/references/profil-modal.jpg))

## Адаптив (телефоны и планшеты)

Дневник — один клиент для детей 7–14 и родителя; на узком экране те же разделы и правила продукта, без отдельного «мобильного» смысла.

### Брейкпоинты (токены SCSS)

| Токен | Значение | Роль |
| --- | --- | --- |
| `$bp-phone` | 640px | Компактная шапка, bottom-sheet модалки, карточки вместо таблиц |
| `$bp-tablet` | 900px | Off-canvas drawer вместо постоянного сайдбара |
| `$bp-laptop` | 1280px | Неделя расписания → список (как раньше) |

### Навигация

- **Широкий экран:** сайдбар 260px / свёрнутый rail 72px (как на десктопе).
- **≤ 900px:** сайдбар — overlay-drawer; в шапке кнопка меню; закрытие по overlay, Esc и смене маршрута.
- Зоны нажатия пунктов меню и ключевых кнопок — **не меньше 44px**.

### Модалки и формы

На телефоне модалки открываются снизу (почти на всю высоту) с учётом `safe-area`. Футеры с несколькими кнопками складываются в столбец.

### Проверка вручную (Safari / Chrome)

- [ ] Открыть меню → перейти в раздел → drawer закрылся
- [ ] Расписание: день / неделя / месяц, раскрытие занятия
- [ ] ДЗ: фильтры, раскрытие, модал загрузки
- [ ] Маркет: покупка; настройки: фото и генерация аватарки
- [ ] Рейтинг и платежи без горизонтальной прокрутки всего экрана
- [ ] Портрет и ландшафт на типичном телефоне/планшете
