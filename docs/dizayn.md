## Брендинг

В живом интерфейсе (сайдбар):

- **Название:** **IT CAMP** + подпись **Гимназия №16**
- **Логотип:** изометрический куб (цветные грани)
- **Маскот:** робот в боковом меню (декор)
- **Тон:** дружелюбный, для детей 7–14 лет — яркие карточки, мягкие скругления, иллюстрации

Макеты в `design/references/` могут ещё показывать старое «IT ШКОЛА» — ориентироваться на код и эту спецификацию. Часть карточек (поля профиля и др.) — без лишней тени.

## UI-kit (из макетов)

### Цвета

| Назначение | Пример |
| --- | --- |
| Основной (кнопки, активное меню) | Фиолетовый `#8B5CF6` |
| Успех / проверено | Зелёный `#10B981` |
| Предупреждение / на проверке | Жёлтый `#F59E0B` |
| Ошибка / просрочено / отклонено | Красный `#EF4444` |
| Информация | Синий |
| Монетки | Золотой / жёлтый |

### Скругления

Карточки и кнопки: **12–24 px** (крупные блоки — больше радиус). Без pill-«таблеток» у чипов.

| Роль | Токен | Значение |
| --- | --- | --- |
| Мелкий вложенный | `$radius-sm` | 8px |
| Контрол / кнопка / чип / пункт меню | `$radius-md` / `$radius-button` / `$radius-chip` | 12px |
| Карточка / виджет | `$radius-card` (= `$radius-xl`) | 20px |
| Крупная поверхность (панель, модалка) | `$radius-2xl` | 24px |
| Круг | `50%` | только точка статуса онлайн |
| Аватар (`BaseAvatar`) | `$radius-md` (крупный `$radius-lg`) | **не** круглый — мягкий квадрат |

### Кнопки

- **Primary** — фиолетовая заливка
- **Secondary** — белая с обводкой
- **Link** — текстовая ссылка

### Статусы домашних заданий (цвет чипа)

| Статус | Цвет |
| --- | --- |
| Текущие | Фиолетовый |
| На проверке | Жёлтый |
| Проверенные | Зелёный |
| Отклонённые | Красный |
| Просроченные | Оранжевый |
| Не сданные | Серый |

### Предметы в расписании

У каждого предмета — **свой стабильный цвет** (точки в календаре, полоска в карточке занятия). Примеры из макета расписания: Python — синий, Scratch — оранжевый, Roblox — фиолетовый.

## Шапка

На всех экранах (кроме входа):

- Хлебные крошки (на телефоне скрыты)
- На главной — приветствие в шапке (на телефоне скрыто)
- Баланс **монеток** (иконка + число) — единый счётчик для всего дневника
- Аватар, ФИО студента, группа — по клику открывается **меню профиля** ([profil-modal.jpg](../design/references/profil-modal.jpg))

## Боковое меню

Структура совпадает с [ekrany.md](ekrany.md): Главная · Учёба · Активность · Магазин · Финансы. **Группы «Профиль» / «Личный кабинет» в сайдбаре нет** — профиль, отзывы, настройки и помощь только из меню аватара в шапке. Активный пункт — фиолетовый фон.

## Адаптив (телефоны и планшеты)

Дневник — один клиент для детей 7–14 и родителя; на узком экране те же разделы и правила продукта, без отдельного «мобильного» смысла.

### Брейкпоинты (токены SCSS)

| Токен | Значение | Роль |
| --- | --- | --- |
| `$bp-phone` | 640px | Компактная шапка, bottom-sheet модалки, карточки вместо таблиц |
| `$bp-tablet` | 900px | Off-canvas drawer вместо постоянного сайдбара |
| `$bp-laptop` | 1280px | Расписание: вкладки День/Неделя/Месяц только шире 1280px; уже — только день + `PeriodNav` |

### Навигация

- **Широкий экран:** сайдбар 260px / свёрнутый rail 72px (как на десктопе).
- **≤ 900px:** сайдбар — overlay-drawer; в шапке кнопка меню; закрытие по overlay, Esc и смене маршрута.
- Зоны нажатия пунктов меню и ключевых кнопок — **не меньше 44px**.

### Модалки и формы

На телефоне модалки открываются снизу (почти на всю высоту) с учётом `safe-area`. Футеры с несколькими кнопками складываются в столбец.

### Проверка вручную (Safari / Chrome)

- [ ] Открыть меню → перейти в раздел → drawer закрылся
- [ ] На телефоне: приветствие на главной скрыто в шапке; хлебные крошки скрыты
- [ ] Расписание / оценки: общий `PeriodNav` по дате; на узком — только день (без вкладок неделя/месяц)
- [ ] Главная: блок посещаемости на телефоне — сводка над графиком (столбцом)
- [ ] ДЗ: фильтры, раскрытие, модал загрузки
- [ ] Маркет: покупка; настройки: фото и генерация Clay-аватарки
- [ ] Рейтинг (таблица / карточки) и платежи без горизонтальной прокрутки всего экрана
- [ ] Портрет и ландшафт на типичном телефоне/планшете
